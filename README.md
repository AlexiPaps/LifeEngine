# LifeEngine

A small calculation engine for **disability insurance (TAE, tab af erhvervsevne)** 

## Tech stack

- **.NET 10 / C#** — the engine.
- **xUnit** and **GitHub Actions** for tests and CI.

## Repository layout

```
src/LifeEngine.Core/
tests/LifeEngine.Tests/
```

## Run

Requires the .NET 10 SDK.

```
dotnet test
```
